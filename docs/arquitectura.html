01

Stack tecnológico

Una web renderizada en servidor (SSR) con Astro. El HTML se genera en Vercel Functions y solo las partes interactivas se hidratan con React ("islas"), así la mayoría de páginas envía muy poco JavaScript.

Framework

Astro 5

output: "server" con adaptador @astrojs/vercel. Páginas .astro y rutas API.

UI interactiva

React 19

Islas: carrito, filtros, buscador, ficha de producto, comparador, calendario, chatbot.

Base de datos

Supabase

PostgreSQL: citas, suscriptores, posts del blog y (nuevo) productos de equipamiento.

Hosting

Vercel

Functions (Node), CDN, Cron semanal del blog, Analytics y Speed Insights.

Emails

Resend

Confirmaciones de cita, contacto y doble opt-in de la newsletter.

IA

Groq · AI SDK

Chatbot flotante y generación automática del artículo semanal del blog.

Contenido

JSON + Markdown

Catálogo de motos en JSON de fabricante; blog en Content Collections + Supabase.

Calidad

Vitest

116 tests: carrito, filtros, buscador, catálogo, validaciones y componentes.

05

De dónde salen los productos de equipamiento

El repositorio src/lib/catalog/equipment.ts consulta Supabase en el servidor con una caché de 60 segundos. Nunca se inventan productos en producción.

Página / APIpide productos
→
equipment.tscaché 60 s
→
Supabaseequipment_products + equipment_variants
→
equipment-mapper.tsfila → EquipmentProduct, stock → disponibilidad

✅ Hay productos

Se muestran los datos reales de Supabase. Es el funcionamiento normal en producción.

🟡 Vacío + DEV o EQUIPMENT_USE_MOCK

Se cargan productos [DEMO] con franja amarilla y noindex. Solo en astro dev y en las previews de develop / feature/redesign.

⬜ Vacío en producción

Estados vacíos profesionales con botón a WhatsApp: "Nuestro catálogo online llega muy pronto".

06

Flujo de compra

El carrito es un store propio sin dependencias (src/lib/commerce/cart.ts), guardado en localStorage y sincronizado entre pestañas. El checkout está desacoplado: hoy envía el pedido por WhatsApp; mañana se enchufa una pasarela sin tocar la interfaz.

ProductCard / PDPelige color, talla y cantidad
→
addToCart()actions.ts · evento add_to_cart
→
Store del carritolocalStorage mk_cart_v1 · contador y toast
→
/carritocantidades, eliminar, totales
→
CheckoutProvidercheckout.ts · begin_checkout
Hoy

whatsapp-order

"Continuar con la compra" abre WhatsApp con el pedido redactado (productos, variantes, subtotal). No afirma pago online ni condiciones de envío.

Futuro

Stripe / Redsys / Shopify…

Implementar CheckoutProvider + endpoint /api/checkout que revalide precio y stock contra Supabase, y activar onlinePaymentEnabled en store-config.ts.

Políticas de la tienda (store-config.ts)

Todo lo no confirmado está en null / false y la interfaz no lo muestra. Al rellenarlo aparecen solos los mensajes de confianza, las páginas /ayuda/* y el cálculo de envío del carrito.

CampoEstadoEfecto al activarlo
onlinePaymentEnabledfalse"Pago seguro" + proveedor de pago en el checkout
shippingnullCoste de envío, umbral de envío gratis y /ayuda/envios
returnsnull"Devoluciones" + /ayuda/devoluciones
pickupInStorefalse"Recogida en tienda"
promoCodesEnabledfalseCampo de código promocional en el carrito
sizeGuideAvailablefalse"Guía de tallas" + /ayuda/tallas

11

Pendientes antes de producción

Requieren datos o decisiones del negocio. Regla del proyecto: no se inventa información.

  • Cargar el catálogo real con fotos (la migración de equipamiento y el bucket productos ya están creados).
  • Confirmar políticas de envío, devoluciones, métodos de pago y recogida en tienda (store-config.ts).
  • Condiciones de venta y derecho de desistimiento antes de cobrar online.
  • Elegir e integrar pasarela de pago (Stripe, Redsys…).
  • Revisar si la tabla citas tiene un CHECK sobre motivo y añadir el valor prueba.
  • Fotos propias para las categorías de equipamiento (hoy solo Cascos tiene foto real).
  • Reseñas reales de clientes y ofertas reales de taller.
  • Crear CNAME develop → cname.vercel-dns.com en el DNS y enlazar el dominio a la rama develop en Vercel.
  • Corregir maxTokens → maxOutputTokens en api/chat.ts (AI SDK v6).
