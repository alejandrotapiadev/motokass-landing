 8. A TENER EN CUENTA (notas importantes)
────────────────────────────────────────────────────────────

⚠ Los emails NO funcionan en producción hasta que:
  1. Se tenga un dominio verificado en Resend (motokass.com)
  2. Se configuren las variables RESEND_FROM y TALLER_EMAIL en Vercel
  Mientras tanto, el formulario guarda la cita en Supabase pero
  no envía confirmaciones.

⚠ Las imágenes del catálogo son URLs externas
  Las imágenes de Rieju y Sherco en los JSON provienen de CDNs de
  terceros (cdn.rieju.com, sherco.com, motostarragona.com, etc.).
  Pueden cambiar o caducar sin aviso. Si una URL falla, la tarjeta
  queda sin imagen. Solución a largo plazo: descargar las imágenes
  y alojarlas en el propio proyecto o en un bucket de almacenamiento.

⚠ Cuando se añadan nuevas motos al catálogo JSON, hay que:
  1. Actualizar public/sitemap.xml con las nuevas URLs /tienda/[slug]
  2. Actualizar la fecha lastmod en el sitemap
  3. Hacer deploy para que el servidor SSR reconozca las nuevas rutas

⚠ La seguridad del panel /admin es básica (cookie sin firmar)
  Es suficiente para uso interno de propietario, pero no para múltiples
  usuarios ni datos muy sensibles. No compartir la URL /admin ni la
  ADMIN_PASSWORD con terceros. En el futuro considerar Supabase Auth.

⚠ WhatsApp con número de fijo no funcionará
  Si WHATSAPP_NUMBER se configura con el número 920... (fijo),
  el enlace wa.me abrirá WhatsApp pero el envío fallará porque
  WhatsApp no opera en líneas fijas. Usar obligatoriamente un móvil.

⚠ El campo 'stock' en los JSON es manual
  El inventario no se sincroniza automáticamente con ningún sistema.
  Cuando una moto se venda o llegue nueva, hay que editar el JSON
  manualmente y hacer un nuevo deploy para que se refleje en la web.

⚠ La tabla 'citas' necesita índices para rendimiento futuro
  Si el negocio crece, añadir índice en la columna 'fecha' y 'estado'
  para que las consultas del panel admin sean rápidas:
  CREATE INDEX idx_citas_fecha ON citas(fecha);
  CREATE INDEX idx_citas_estado ON citas(estado);
